# Hisaab Khata Frontend (React + TS + MUI)

## Prerequisites
- Node.js 18+ (recommended)

## Setup
```bash
npm install
npm run dev
```

App runs on: http://localhost:5173

## Environment
Create `.env` (optional) using `.env.example`:
- `VITE_API_BASE_URL` (default: http://localhost:8080)
